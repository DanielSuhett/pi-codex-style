# Security

`pi-codex-style-tools` is a Pi extension and, like every Pi extension, runs
with the user's permissions. Review the source before installing any version.

Do not publish vulnerabilities in public issues. Use the
[GitHub Security Advisories](https://github.com/DanielSuhett/pi-codex-style/security/advisories/new)
to send a private report. If the form is unavailable, contact the maintainer
privately through GitHub.
